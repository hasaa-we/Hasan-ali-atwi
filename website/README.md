# Cybersecurity Learning Portal

This folder contains a static interactive website generated from the Python quiz modules.

## Files
- `index.html` — main website shell
- `styles.css` — visual styling
- `app.js` — quiz UI and interaction logic
- `modules.js` — generated module data from the Python source files

## Run
1. Open `website/index.html` in a browser.
2. Select a module and follow the guided concept pages and quiz questions.

No server is required.
